# 🔐 Password Generator

## Description

A simple Password Generator built using HTML, CSS, and JavaScript that creates random passwords with customizable length, uppercase and lowercase letters, numbers, and symbols.

## Purpose

The purpose of this project is to practice JavaScript functions, DOM manipulation, user input handling, and event handling by building a useful web application.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Generate random passwords
- Customize password length from 4 to 50 characters
- Include uppercase and lowercase letters
- Include numbers and symbols
- Copy the generated password to the clipboard
- Simple and responsive user interface

&#x20;How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Choose the password length and character types.
5. Click **Generate Password**.
6. Click **Copy** to copy your password.
